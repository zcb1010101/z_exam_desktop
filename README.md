# 大斌考试桌面系统

简约大气的考试倒计时应用。零依赖、单文件实现，直接双击 `index.html` 即可使用，完全离线可用。


## 功能

- **考试倒计时**：未开始时显示"距离开考"，进行中显示"考试进行中"，结束后显示"考试已结束"，跨天自动带天数
- **实时时钟**：当前日期与时间每秒刷新
- **页面内配置**（右上角齿轮打开设置面板，保存在浏览器 localStorage，刷新不丢失）：
  - 考试科目
  - 开始 / 结束时间
  - 背景：4 种内置渐变（深空 / 深海 / 极光 / 朝霞）或上传自定义图片（自动压缩以适配本地存储）
  - 字体样式：考试科目 / 时间 / 倒计时可分别调节字号（滑块）和颜色（取色器），调整时页面实时预览，可一键恢复默认；字号仍带响应式上限，小窗口自动收缩
  - 考试守则：每行一条，可控制在页面上的显示
- **一键全屏**：右上角全屏按钮，适合投屏 / 副屏展示
- **页面可滚动**：内容超出窗口高度时自动出现滚动条，守则等底部内容始终可达

## 技术说明

纯 HTML + CSS + 原生 JavaScript，无任何外部资源或网络依赖。所有配置持久化于 `localStorage`（键：`exam-desktop-config-v1`），如需重置可清除该键或清除浏览器站点数据。
